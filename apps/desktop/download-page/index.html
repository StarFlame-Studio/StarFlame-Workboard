安装说明
1. 双击安装包，选择安装位置（默认装在当前用户目录，无需管理员权限）；
2. 首次启动后扫码或在设置页填写班级码与授权码完成绑定；
3. 之后的版本更新会在应用内提示，下载完成后退出应用即自动安装。

便携版解压到任意文件夹，双击 StarflameWorkboard.exe 即可运行，不写入注册表。
安装包已用「焰火工作室」代码签名证书签名；若这台电脑还没信任该证书，Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。
应用内更新失败，提示「不是由应用所有者签名」？ 现象：检测到新版本后，下载完成后报「not signed by the application owner / 不是由应用所有者签名」。 原因是这台电脑还没把「焰火工作室」的代码签名证书加入受信任根。
下载下面的 install-cert.bat 与 starflame.cer，放在同一个文件夹里，双击 bat 运行即可 （无需管理员权限，只写入当前用户；若以管理员运行则对全机生效）。脚本会自动清理失败的更新缓存， 然后回到「星焰作业板 → 设置 → 关于」点「检查更新」，这次会正常下载并自动安装。
脚本失败时手动导入：右键 starflame.cer → 安装证书 → 当前用户 → 「将所有的证书都放入下列存储」→ 浏览 → 受信任的根证书颁发机构。
也可以直接用上面的 1.2.1 安装包覆盖安装，已绑定的班级与本地缓存都不会丢。
